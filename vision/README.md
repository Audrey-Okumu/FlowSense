# FlowSense Vision

This folder contains the computer-vision part of FlowSense. It analyzes the sample traffic video, detects and tracks vehicles, counts detections in predefined lane zones, and writes an annotated video and a JSON timeline.

## Folder guide

| Path | Purpose |
|---|---|
| `vision/traffic_analysis.py` | Main video-processing script: YOLO detection, ByteTrack tracking, lane-zone counts, video annotations, and JSON output |
| `data/traffic_analysis.mp4` | Input traffic video |
| `data/traffic_analysis.pt` | YOLO model weights |
| `data/traffic_analysis_result.mp4` | Annotated video generated by the script |
| `data/lane_counts.json` | Per-sampled-frame lane counts and timestamps |
| `requirements.txt` | Python dependencies, including the compatible Supervision version |

Run commands from the **repository root** (the folder containing `requirements.txt`), not from inside `vision/`. The script's default input and output paths are relative to that root.

## Set up and run (Windows PowerShell)

The large video and model files are stored using Git LFS. From the repository root, run:

```powershell
git lfs install
git lfs pull
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe vision\traffic_analysis.py
```

Create the `.venv` only once. On later runs, skip `python -m venv .venv`; run the script with the `.venv` Python command shown above.

The terminal displays processing progress. When the run finishes, open `data\traffic_analysis_result.mp4` to view the result, or inspect `data\lane_counts.json` for the numeric output. Existing output files are overwritten.

## What the script does

1. Loads `data/traffic_analysis.pt` and `data/traffic_analysis.mp4`.
2. Samples every other frame and runs YOLO detection with the configured confidence and IoU thresholds.
3. Uses ByteTrack to associate detections with track IDs between sampled frames.
4. Counts detections inside the predefined entry zones and tracks vehicles from entry zones to exit zones.
5. Draws zone polygons, detection boxes, track labels/trails, and accumulated movement counts on each processed frame.
6. Saves the annotated video and a JSON timeline containing each sampled frame number, timestamp, and lane counts.

The JSON lane labels are `north`, `south`, `west`, and `east`, in the order defined in `traffic_analysis.py`.

## Notes for contributors

- Keep vision-processing code in this folder. Put shared input data and generated outputs in the repository's `data/` folder.
- Add any new Python package dependency to the root `requirements.txt`.
- The current script produces vehicle-detection and counting outputs. It does not yet control traffic lights or run a SUMO simulation.
- The output video is written at the source video's FPS even though only every other frame is processed, so playback can appear faster and shorter than the source.
- There is no live video preview; follow progress in the terminal and view the output video after processing completes.
